## 上线到 GitHub Pages

1. 到 github.com 开一个 repo（例如 `0814`）
2. 把 `index.html` 拖进去 → Commit
3. repo → **Settings → Pages** → Source 选 **Deploy from a branch** → `main` / `(root)` → Save
4. 一两分钟后就会活在：
   `https://<你的帐号>.github.io/0814/`

想沿用上週的网址格式，把档名改成 `challenge.html`，
网址就是 `https://<你的帐号>.github.io/0814/challenge.html`

## 玩法

- 👥 玩家：加名字、手动加减分、分数归零
- 👀 全部翻开：给他们记位置，倒数完自动盖回
- 🔀 洗牌：重新随机排位置，分数保留
- 🔁 配到也换人 / 配到再来一次
- L1 6 对｜L2 8 对｜L3 10 对

分数和名单存在浏览器里，中途重整不会不见。
